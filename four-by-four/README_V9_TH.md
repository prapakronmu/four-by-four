# Dashboard V9 — Interactive Executive Edition

สร้างต่อจาก V8 โดยรักษาชุดข้อมูลดั้งเดิมและแผนที่ตำแหน่ง 77 จังหวัดไว้

## ฟังก์ชันใหม่
- คลิกตำแหน่งจังหวัดบนแผนที่เพื่อเลือกจังหวัด
- คลิกกราฟฝน/ผลผลิตตามปี–เดือนเพื่อกรองปีและเดือน
- คลิกกราฟจังหวัดเพื่อกรองจังหวัด และคลิกกราฟรายเดือนเพื่อเลือกเดือน
- แท็บสำรวจข้อมูลที่สามารถเรียง ค้นหา และพลิกหน้าตาราง
- ดาวน์โหลด CSV ตามตัวกรองปัจจุบัน (Excel ภาษาไทยใช้ UTF-8 BOM)
- ปรับธีมและกรอบแบนเนอร์ให้ใกล้กับภาพตัวอย่างของผู้ใช้

## ขอบเขตของฟังก์ชัน
- ดาวน์โหลดข้อมูลจริงที่มีอยู่เท่านั้น ไม่มีการสร้างค่าจังหวัดที่ขาด
- ตัวเลือกครอบคลุม 77 จังหวัด แต่ข้อมูลเดิม 52 จังหวัด × 6 ปี × 12 เดือน = 3744 แถว
- หน้า HRDI แยกชนิดปีและแหล่งข้อมูลจากชุดหลัก ไม่ควรรวมตัวเลขเข้าด้วยกัน
- แผนที่เป็นพิกัดจุดจังหวัดโดยประมาณ **ไม่ใช่พื้นที่รูปทรงจังหวัดจริง** จนกว่าจะมี GeoJSON ที่ตรวจสอบแล้ว
- ตัวเลขยางพาราในข้อมูลเดิมยังไม่ได้รับรองเทียบ OAE
- คลิกกราฟเป็นการเลือกค่าเดียวในมิตินั้นเพื่อเจาะรายละเอียด ตัวกรองหลายค่าเลือกจาก Dropdown
- เว็บไซต์ตัวอย่างไม่สามารถอ่านเนื้อหาได้โดยตรงจากสภาพแวดล้อมขณะพัฒนา จึงยึดภาพตัวอย่างและข้อกำหนดผู้ใช้ มิใช่การคัดลอกเว็บเป๊ะ

## วิธีเปิด
แตก zip → เปิดโฟลเดอร์ four-by-four → ดับเบิลคลิก START_DASHBOARD.bat → เปิด http://127.0.0.1:8050
ปิดโปรเซส Dashboard เก่าก่อนรันเพื่อเลี่ยงพอร์ตชน

## สถานะทดสอบ
ผ่านการตรวจ syntax (py_compile); ยังไม่ได้ทดสอบบราวเซอร์แบบ End-to-End จริงในสภาพแวดล้อมนี้
