- เพิ่มแบนเนอร์ Halloween executive ตามภาพอ้างอิงที่ผู้ใช้แนบ (ไฟล์ `assets/halloween-banner.png`)

- ชี้แผนที่เพื่อดูค่าฝน/ผลผลิตจากไฟล์เดิม และคลิกจังหวัดเพื่อกรอง dashboard ทั้งหมด
- ตัวเลือกสลับฝนเฉลี่ยกับผลผลิตรวม; แผงรายละเอียดจังหวัดและการจัดอันดับในช่วงเวลาที่เลือก
- ช่วงเวลา/จังหวัดและกราฟเดิมทุกแท็บใช้ DataFrame ที่ถูกกรองร่วมกัน
- สีเทาหมายถึงข้อมูลขาดในตัวกรอง (ไม่เท่ากับ 0)
- ไม่แก้ต้นทางของไฟล์ `data/balanced_panel_BE2562-2567.csv`

## เริ่มต้น Windows

1. แตกไฟล์ ZIP (อย่ารันจากภายใน ZIP)
2. เปิด `START_DASHBOARD.bat` (Python และอินเทอร์เน็ตจำเป็นเฉพาะติดตั้ง packages หากยังไม่มี)
3. เปิด http://127.0.0.1:8050
4. ถ้าแผนที่ไม่แสดง ให้รีเฟรชหน้าเว็บ และดูข้อความข้อผิดพลาดในหน้าต่างคำสั่ง

## ขอบเขตข้อมูลและความซื่อสัตย์ในการนำเสนอ

- ชุดเดิม 52 จังหวัด ปี 2562–2567; 25 จังหวัดอื่นแสดงว่าไม่มีข้อมูลในไฟล์นี้
- `tons` เป็นข้อมูลจากชุดเดิมที่ **ยังไม่ได้ยืนยันเทียบ OAE**; อย่าอ้างเป็นสถิติทางการจนกว่าจะตรวจสอบและแทนที่
- ข้อมูลผลผลิตรายเดือนในชุดเดิม **ต้องตรวจ provenance** ก่อนอ้างว่าเป็นค่ารายเดือนที่หน่วยงานวัดจริง
- ฝนเฉลี่ยข้ามพื้นที่หรือเดือนใน UI เป็นค่าเฉลี่ยเลขคณิตของรายการที่เลือก ไม่ใช่ผลรวมปริมาณฝน และหากช่วงเวลาไม่ครบ ค่านี้อาจเกิด sampling bias
- พิกัดจังหวัดใน `province_approx_locations.csv` เป็นพิกัดเพื่อการนำทางภาพรวม ไม่ใช่พิกัดศูนย์กลางที่หน่วยงานราชการรับรอง
- รายการที่ขาดไม่ควรถูกตีความว่าไม่มีสวนยาง หรือผลผลิตเท่ากับศูนย์

## เปิดโหมดแผนที่ขอบเขตจังหวัดจริง

ให้วางไฟล์ `data/thailand_provinces.geojson` ที่ได้สิทธิใช้งานและผ่านการตรวจสอบว่าเป็น FeatureCollection มี 77 features (หนึ่งจังหวัดต่อหนึ่ง feature) และมีหนึ่งในฟิลด์ `province`, `name_th`, `NAME_1`, `NAME_TH` ซึ่งมีชื่อจังหวัดภาษาไทยตรงกับ `thailand_77_provinces.csv` ทั้ง 77 รายการ ชื่อจังหวัดต้องไม่ซ้ำและไม่มีจังหวัดตกหล่น ระบบจะเปลี่ยนเป็น polygon map อัตโนมัติหลังรีสตาร์ต ถ้าตรวจสอบไม่ผ่าน ระบบจะคงแผนที่ตำแหน่งโดยประมาณไว้และไม่อ้างว่าเป็น polygon map

**หมายเหตุ:** ยังไม่ได้แนบไฟล์ GeoJSON ขอบเขตจังหวัดที่ตรวจสอบแล้ว เนื่องจากเซสชันนี้ดาวน์โหลดจากภายนอกไม่ได้ แผนที่ V8 จึงใช้จุดตำแหน่งที่ระบุข้อจำกัดไว้อย่างชัดเจน

## แหล่งข้อมูลสำหรับขั้นต่อไป

1. HII ฝนรายจังหวัด-เดือน https://data.go.th/dataset/spatial-rain
2. OAE ผลผลิตยางรายจังหวัด-ปี https://catalog.oae.go.th/th/dataset/dataoae1404
3. OAE ร้อยละการกระจายผลผลิตรายเดือน https://catalog.oae.go.th/th/dataset/para_rubber_product_month

ข้อมูลผลผลิตรายเดือนที่สร้างจากผลผลิตรายปี × สัดส่วนรายเดือน ต้องติดป้าย `derived` และระบุว่าเป็นค่าประมาณ ไม่ใช่ค่ารายเดือนที่วัดจริง

## งานค้างเพื่อเปิดใช้ในเชิงวิชาการ

- ดาวน์โหลดและตรวจ GeoJSON ขอบเขตจริงพร้อมสิทธิการใช้งาน
- จัดหาไฟล์ XLSX OAE และทดสอบการ join ชื่อจังหวัด/ปี กับไฟล์ HII
- ตรวจสอบผลผลิตรายจังหวัด ปี 2562–2567 และวิธีแจกแจงรายเดือน
- เพิ่ม separate metric flags `observed`, `derived`, `unavailable` แยกฝนและผลผลิต
- ทดสอบ UI ผ่าน Chrome/Edge บน Windows จริง รวมถึง clear/reset/filter/map hover/click และ export
