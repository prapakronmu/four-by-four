# Dashboard สร้างใหม่ (เวอร์ชันเน้นความเสถียร)

## เหตุผลที่รื้อระบบ
ไฟล์ app.py เดิมมีการสร้าง/สลับเนื้อหาแบบซับซ้อนและมีรายงานผู้ใช้ว่าบางแท็บไม่แสดงข้อมูล จึงสร้าง app.py ใหม่ที่เรียบง่าย โดยไม่แก้ไฟล์ CSV ต้นฉบับ

## เริ่มต้น
1. แตก ZIP ใหม่ **อย่าทับโฟลเดอร์เดิม**
2. ติดตั้ง Python 3.10+ ถ้ายังไม่มี และเลือก Add Python to PATH
3. Windows: ดับเบิลคลิก START_DASHBOARD.bat (ต้องมีอินเทอร์เน็ตครั้งแรกเพื่อติดตั้งไลบรารี)
4. เข้าหน้า http://127.0.0.1:8050
5. หากเคยเปิดเวอร์ชันเก่า ให้ปิดหน้าต่างโปรแกรมเวอร์ชันเก่าก่อน (Ctrl+C) เพราะใช้พอร์ตเดียวกัน

## การกรอง
- จังหวัด ปี เดือน: เลือกหลายค่าได้ กด x ล้างค่าแต่ละรายการ กด 'ล้างทั้งหมด' ล้างทั้งสามตัวกรอง
- ตัวกรองจะอัปเดต KPI และกราฟทุกแท็บของ **ข้อมูลหลัก**
- แท็บ HRDI เป็นอีกฐานข้อมูล: กรองจังหวัดได้ แต่ไม่ได้กรองปี/เดือนจากข้อมูลหลัก (ปีใน HRDI คือ ค.ศ. และช่วงเวลาไม่ตรงกัน) มีคำเตือนบนแท็บอย่างชัดเจน
- กราฟเปรียบเทียบ: แท่งผลผลิตรวมตัน / เส้นฝนเฉลี่ย มม. ใช้สองแกน ไม่ควรเปรียบเทียบความสูงแท่งกับเส้นโดยตรง
- Scatter Plot: แต่ละจุดแทนจังหวัด–ปี–เดือน **ไม่มีความหมายว่าเหตุและผล**

## ข้อจำกัดก่อนใช้งานจริง
- ยังไม่ได้ยืนยันแหล่งต้นทางทางการของคอลัมน์ `tons`; ห้ามนำตัวเลขไปอ้างอิงเป็นข้อมูลทางการโดยไม่ตรวจต้นทาง
- ฝนเฉลี่ยคำนวณจากค่าเฉลี่ยของแถวใน CSV ไม่ใช่การถ่วงน้ำหนักตามพื้นที่/จำนวนสถานี
- เวอร์ชันนี้เป็น clean rebuild เพื่อให้แสดงทุกแท็บก่อน ยังไม่ได้เพิ่มการคลิกจุดกราฟเพื่อเปลี่ยนตัวกรอง (ป้องกัน callback ซ้อนกันและค่าค้าง)
- เครื่องตรวจสอบที่ใช้สร้างไฟล์ไม่มี Dash จึงตรวจ syntax + data tests ได้ แต่ยังไม่ได้ browser end-to-end test

## ตรวจข้อมูล
รัน `python check_data.py`

## หากแท็บยังขาวหรือเกิด error
เปิดหน้าต่างคำสั่งที่รัน Dashboard และส่งภาพข้อความ error ทั้งหมด รวมทั้งภาพแท็บที่มีปัญหา; กด Ctrl+F5 บน browser เพื่อล้าง cache หน้าเว็บเก่า
