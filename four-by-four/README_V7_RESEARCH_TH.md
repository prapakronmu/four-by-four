# Dashboard V7 — ข้อมูลอ้างอิงและการตรวจสอบความครอบคลุม (29 ต.ค. 2569)

## สิ่งที่เพิ่ม
- ใช้โค้ด V6 เป็นฐาน รักษา 5 แท็บเดิมไว้
- เพิ่มแท็บ **ความครอบคลุม 77 จังหวัด** แสดงจำนวนระเบียนจริง คาดหวัง และข้อมูลที่ขาด
- เพิ่มรายชื่อ 77 จังหวัดในตัวเลือก (จังหวัดที่ยังไม่มีข้อมูลจะแสดงเป็นไม่มีข้อมูล ไม่เติมตัวเลข)
- เพิ่ม `check_coverage_v7.py` และรายงาน `data/coverage_77_provinces_audit.csv`

## ประเด็นสำคัญ
ข้อมูล `balanced_panel_BE2562-2567.csv` ครบทุกเดือนสำหรับ 52 จังหวัด **แต่ไม่ใช่ข้อมูลทุกจังหวัดของประเทศไทย** และไม่ควรสร้างผลผลิตยางพาราในจังหวัดอื่นด้วยการเดาหรือใส่ศูนย์

## แหล่งข้อมูลทางการที่ค้นพบสำหรับเพิ่มข้อมูลในอนาคต
1. ข้อมูลฝนเชิงพื้นที่รายเดือนรายจังหวัด สถาบันสารสนเทศทรัพยากรน้ำ: https://data.go.th/dataset/spatial-rain (CSV; ชุดข้อมูลครอบคลุมปี 2562–2568; หน่วย มม.)
2. ปริมาณการผลิตยางพารา ระดับจังหวัด สำนักงานเศรษฐกิจการเกษตร: https://data.go.th/dataset/dataoae1404 (ข้อมูลรายปี: เนื้อที่กรีดได้ ผลผลิต ผลผลิตต่อไร่)
3. ร้อยละปริมาณผลผลิตยางพารารายเดือน ระดับจังหวัด สำนักงานเศรษฐกิจการเกษตร: https://catalog.oae.go.th/th/dataset/para_rubber_product_month

**ยังไม่ได้ดาวน์โหลดและผนวกไฟล์จากแหล่งใหม่** ลง Dashboard นี้ เนื่องจากสภาพแวดล้อมไม่สามารถเชื่อมต่อดาวน์โหลดไฟล์โดยตรงได้ การรวมข้อมูลต้องตรวจคอลัมน์ ช่วงปี จังหวัด หน่วย และใบอนุญาตก่อน

## ข้อควรระวังการวิเคราะห์
- ข้อมูลผลผลิตรายเดือนจากไฟล์เดิมยังไม่ได้ยืนยันกับไฟล์ต้นทาง สศก. ว่าเป็นตันจริง
- การใช้ผลผลิตรายปีร่วมกับฝนรายเดือนจะต้องทำที่ระดับเวลาสอดคล้องกัน ห้ามนำค่ารายปีไปทำเสมือนเป็นผลผลิตรายเดือน
- ฝนเฉลี่ย (มม.) ไม่ใช่ผลรวมฝนของหลายจังหวัด หน่วยวัดฝนและผลผลิตต่างกัน
- จังหวัดไม่มีข้อมูล ≠ ฝน 0 มม. หรือยาง 0 ตัน
- อย่าตีความ Scatter Plot เป็นความสัมพันธ์เชิงเหตุผล โดยไม่ตรวจความเอนเอียงและฤดูกาล
